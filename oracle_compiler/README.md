# Oracle Compiler

This is the shallow control surface for the Foundry Oracle Ingest Compiler.
It is durable architecture and routing, not present-tense task state.

**Task authority lives on GitHub Issue #1: latest `K` -> active `T`.**
Read `refoundation/SESSION-PROTOCOL.md`; this workspace adds no second protocol.

Cold-start compiler reading order:

1. `V1.md` — Captain-ratified compiler architecture.
2. `OWNERSHIP.md` — writable surfaces, read-only dependencies, and STOP boundaries.
3. `PLAN.md` — dependency/package map only; it does not select work.
4. `INTERFACES.md` — currently frozen compiler interface level.
5. Issue #1 — resolve the active task before execution.

`RESULTS.md` appears only after a reviewed result exists. `FIXTURES.json` is created by M02.
S16A, S16B, and AQ4 are task-specific evidence only when the active `T` names them.

`archive/` is inert history. Historical files may explain prior work but never assign current work.
