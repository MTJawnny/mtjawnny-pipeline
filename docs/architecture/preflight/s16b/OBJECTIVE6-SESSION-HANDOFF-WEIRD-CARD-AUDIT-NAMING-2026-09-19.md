## 3. Major changes relative to this original handoff

The adversarial evidence changed several working decisions rather than merely renaming them:

- `Bounded Extraction` -> **Sample Selection**, surfaced finite-sample signature; generic Card Filtering demoted to broad UI/search umbrella;
- `Access Horizon` -> **Permission Window** coordinate;
- `Sequential Library Traversal` -> **Library Traversal** event signature with explicit stop-rule structure;
- `Repeat-Use / Additional Execution` -> **Additional Execution** signature;
- `Resource-Type Separation` -> **Typed Resources** substrate invariant;
- `Card Resource Differential` -> proposed **Card Resource Delta**, a derived accounting fact rather than a family;
- separate `Card Access Differential` -> retired, no replacement;
- canonical Engine hierarchy -> demoted; hard processor/throughput facts retained, `Engine` remains derived/search/community language;
- `Alternate Payment` umbrella -> split into Cost Reduction, Alternative Cost, Additional Cost, and Payment Method;
- `Deployment Bypass` -> **Direct Placement**;
- rigid Fast Mana child rule -> demoted to a derived/community surfaced tag over measured acceleration facts.
