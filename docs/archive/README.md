# docs/archive — spent material, kept for audit trail

Documents here are executed directives, rejected proposals, or superseded
reports. They are **not** current law and must not be cited as such.

Entry gate — a doc may only land here when
`experiments/foundry_ruling_registry.py --check <doc>` reports it is the
sole home of no ruling, AND it is not referenced as live law by CLAUDE.md
or loaded by code. Archived docs drop out of the registry scan (it globs
`docs/*.md`, not subdirectories), so a doc carrying a sole-home ruling
must never be moved here.

Nothing is deleted; git history is the real record either way.
