## 1. The shape

> **CR 113.3d** — *"Static abilities are written as statements. **They're
> simply true.**"*
> **CR 604.1** — *"Static abilities create continuous effects…"*

`Creatures you control get +1/+1.` is such a statement. This branch is the
**sibling of `static-self-statement`**: the same CR 113.3a closure — a card
with no instant or sorcery face leaves CR 113.3's four-category enumeration
closed on `static` — applied to a different **subject**. Where that branch
states something about the card itself, this states it about a class of *other*
permanents.

**238 distinct subjects across 524 lines, and every one was read.** They range
from `Creatures you control` (55) through `Other Wolves and Werewolves you
control` to `Creatures controlled by players who chose peace`. All 382 distinct
line texts were read as well.

## 2. THE SUBJECT IS A NOUN PHRASE, NOT A CLAUSE — and CR 113.3c is why

The pattern is `^(subject) get(s) ±N/±N` where the subject may contain **no
period and no comma**.

> **CR 113.3c** — *"Triggered abilities have a trigger condition and an effect.
> They are written as '[Trigger condition], [effect]'."*

So a comma inside what this calls the subject means **a trigger condition has
been swallowed**. An earlier draft without that constraint matched

```
Whenever this creature attacks, it gets +1/+1.
```

and `foundry_probe.must_capture` halted on it before it ever ran against the
corpus. `[^.,]` is doing CR 113.3c's work; it is not saving characters.

**There is deliberately NO length cap.** The first draft carried one (70
characters), and it made **Paliano Vanguard**'s fate depend on how long its own
name is — the cap was reached before the predicate on the raw line and not
after self-reference canonicalization. A character count is a tuning knob, and
the engine rules do not allow one.

## 3. Placement: the TAIL, which makes zero re-routes structural

Reached only after loyalty, activated, every trigger family, `replacement`, the
attachment branch and `static-self-statement` have all declined. **A new tail
branch can only claim lines that already reached `spell-or-static`**, so zero
re-routes is a guarantee of the placement rather than a lucky result — the
observation `STEP-2B` §2b records, applied again.

It matters here more than usual: `Equipped creature gets +2/+2` and `Enchanted
creature gets -2/-0` are the same *predicate* on ~1,300 lines, and they are
already correctly `static` via the attachment branch. A probe that forgot the
population filter measured all of them; the branch cannot, because they never
reach it.

## 4. Four refusals, each owned by a rule, each found by reading the output

| refused | rule | n |
|---|---|--:|
| `Visit — Creatures you control get +1/+0 until end of turn.` | **CR 702.159a** | 2 |
| `Solved — …` | **CR 702.169a** | 1 |
| `• Temur — Creatures you control get +1/+0 …` | **CR 700.2** | 1 |
| Criminal Past — `…have menace and "This creature gets +X/+0…"` | **§2 created ability** | 1 |

**The keyword refusal is derived, not named.** `Visit` and `Solved` are CR 702
keywords whose parameter is an ABILITY, so `ability_word_prefix` strips them on
purpose — and a `Visit —` line, stripped, reads as a static because CR 702.159a
put the *trigger condition* in the keyword: *"'Visit — [Effect]' means
'Whenever you roll to visit your Attractions…'"*. The branch therefore asks
whether the prefix it stripped was a **CR 702 keyword** rather than a CR 207.2c
ability word, using **`CR_KEYWORD_NAMES`** — the parsed membership list, never
`KEYWORD_HOME`, which skips undecidable keywords and would answer "no" for a
keyword it merely could not place. `Visit`'s own `effective_classes` is `[]`
(the CR says only *"is a keyword ability"*, which `NOT_A_CLASS` correctly
refuses), so a class-based test could not have caught it.

> The two `Visit` cards are Attractions, which `docs/OUT-OF-SCOPE.md` measured
> and **declined**. Reported here as declined, not as open. The general
> observation — that stripping `Visit —` leaves a triggered ability looking
> static — is recorded in §7 and is not this pass's business.

**Criminal Past is a real finding, and it belongs to STEP-2A's shape B.** The
line is `Commander creatures you own have menace and "This creature gets +X/+0,
where X is the number of creature cards in your graveyard."` It *is* a static —
a quoted grant — but shape B does not claim it, so it sits in `spell-or-static`
today. This branch refuses it because §2 assigns a quoted ability's delivery to
whatever it was granted to; claiming it would be the right answer for a reason
living inside somebody else's ability.

> **CORRECTED 2026-08-09 by `W4-KEYWORD-GRANT-2026-08-09.md` §8.** §9 below
> predicted this line would be claimed by the keyword-grant shape. **It is
> not** — its grant is MIXED (one bare keyword plus one quoted ability), so the
> granted text is not entirely keywords and that shape correctly declines it
> too. It is a shape B miss and nothing else.

## 5. THE CLASSIFIER WAS WRONG BY 9, AND ONLY THE RECONCILIATION FOUND IT

The probe measured **524**; the first live diff moved **515**.

`STEP-2B` §4 records the same disagreement in the other direction (probe 400,
classifier 443) and its lesson was *"suspect the check"*. **Here the check was
right and the classifier was wrong.** The 9:

```
Jodah, the Unifier      Legendary creatures you control get +X/+X, where X is …
Meishin, the Mind Cage  All creatures get -X/-0, where X is the number of cards …
Samut, the Driving Force Other creatures you control get +X/+0, where X is your speed.
Knowledge Is Power · Kinbinding · Gornog · Hancock · Minthara · Teysa
```

`ANTHEM_SUBJECT` is applied to `low` — the **lowercased** body, as every other
branch is — while its character class read `[0-9X*]`. CR 107.3's variable `X`
had already been case-folded to `x`, so **every variable anthem in the corpus
was silently lost**. Fixed to `[0-9Xx*]`.

**Neither number alone would have shown it.** The diff's 515 was internally
consistent, all `None → static`, and would have read as a clean pass; the
probe's 524 was equally self-consistent. Only insisting the two agree exposed
it — the same discipline as "a count is not a measurement", applied to two
measurements of the same thing.
