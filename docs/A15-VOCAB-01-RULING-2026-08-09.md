### 10a. THE QUOTE PROBLEM, AND WHY THE RE-WALK IS SAFE

An A1 assertion needs a **quote** per `(slug, oracle_id)`, and
`classify_run1_instances` returns `{slug: set(oracle_id)}` — **the quote is
dropped on the floor.** So it has to be recovered by walking the parsed run-1
file again, and re-implementing a classifier's walk is this repo's most
expensive recurring defect.

So the re-walk is **not trusted on its own**. It applies the producer's own
gates, and then its reconstructed hit-sets are asserted **equal to the
producer's — every slug, every oracle_id, both directions, per lane.** Any
divergence halts. The re-walk is only ever a quote lookup;
`classify_run1_instances` stays the authority on which rows exist.

**Same-run duplicates are a LOOKUP, never a re-decision.** 44 cards emit one
axis twice; `pick_quote` reads 2a's `winning_quote` and **halts** if 2a did not
resolve the pair. CDR-04's "keep both quotes in one assertion" is a *proposal*,
not ratified — directive §1 binds, so 2a's frozen collapse wins.
