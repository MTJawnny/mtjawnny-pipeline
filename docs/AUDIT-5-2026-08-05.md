Six commits landed this session (`5a6479b` .. `db32841`). This audit uses the
four standing methods — **emitter census, recall inversion, partition
reconciliation, metamorphic** — because sampling cannot claim completeness.

## 1. EMITTER CENSUS — every ratified token, its members, its emitter

The standing trap: *"a ratified token with no emitter looks exactly like one
with no members."* All **53** §2 tokens checked against both.

### FINDING 1 — `kicker` is a ratified DELIVERY token that §2b makes unreachable

| | |
|---|---|
| members | **0** |
| emitter | **none** |
| corpus lines printing `Kicker …` | **216**, all routed to `static` |

**§2 and §2b contradict each other, and §2b is right.**

> **CR 702.33a** — *"Kicker is a **STATIC ABILITY** that functions while the
> spell with kicker is on the stack. 'Kicker [cost]' means 'You may pay an
> additional [cost] as you cast this spell.'"*

§2b (Captain-ratified 2026-08-03) says a CR 702 keyword's delivery is **derived
from its `702.Na` class**. That class is `static`, so `KEYWORD_HOME["kicker"]`
is `static` and the router is behaving correctly. The `kicker` row in §2's table
predates §2b and was never retired.

**PROPOSED FIX — needs Captain, because retiring a ratified token is
vocabulary.** Retire `kicker` from §2 exactly as `delayed` was retired by §2d:
a struck-through row pointing at §2b. It is not a delivery; it is an
**additional cost** (CR 601.2b) whose ability class is static (702.33a).

### FINDING 2 — the `any-` collision reaches the TOOLING, not just the tokens

This audit's own script mis-counted `any-damage-to-*` members, because stripping
the §2a subject prefix `any-` off `any-damage-to-creature` yields
`damage-to-creature`. **The name collision documented in
`VOCABULARY-COMPLETION-2026-08-05.md` §1 is not confined to the classifier** —
any consumer that normalises §2a prefixes will corrupt these four token names.
**PROPOSED FIX:** prefix-stripping must be anchored to the ratified token list
(strip only if the remainder is itself a §2 token), never applied blindly.

## 2. RECALL INVERSION — what the session's branches did NOT claim

The method that matters, because every defect the 2026-08-04 pre-step-2 audit
found was a recall failure. **189 lines across three defects.**

### FINDING 3 — `\b` after "as " rejects `~`, losing 25 CR 614.1c replacements

```
Stenn, Paranoid Partisan   As Stenn enters, choose a card type other than creature or land.
Pramikon, Sky Rampart      As Pramikon enters, choose left or right.
```

The replacement branch tests `^as (?!an additional cost|long as)\b…`. After
canonicalization the line reads `as ~ enters`, and **`~` is not a word
character**, so the `\b` immediately after `as ` cannot match. **25 unrouted
lines** carrying CR 614.1c's own second template.

This is the recorded trap — *"`~` is not a word character, so `\b~\b` can never
match"* — which the file already fixed in `selfish` and in the compound-trigger
subject test, **surviving in a third place.** A trap fixed at two sites and not
swept is a trap that is still live.

**PROPOSED FIX (DET, no vocabulary):** drop the `\b`, or make it `(?:\b|(?=~))`.
Then re-diff — the `enters` branch is load-bearing for 2,390 `replacement` lines.

### FINDING 4 — `ABILITY_WORD` cannot strip a prefix with a DIGIT or punctuation — 121 lines

```
ABILITY_WORD = re.compile(r"^\s*[A-Z][A-Za-z'’\- ]{2,40}\s*—\s*")
```

CR 207.2c ability words are *"italicized words with no rules meaning"*, and the
corpus prints plenty with characters this class excludes:

| printed | lines |
|---|--:|
| `Descend 4 —` · `Descend 8 —` | digits |
| `Awaken 4—{4}{W}` · `Prototype {1}{B} — 1/1` | digits and mana symbols |
| `10—19 \|` (die-roll rows) | digits |
| `Nitro-9 —` · `No One Dies! —` | digit; punctuation |

**121 unrouted lines**, and the damage is not confined to one branch — the same
gap cost recall on `^as long as` (Akawalli, the Seething Mass), on the trigger
branches (Ace, Fearless Rebel), and forced a **local** dash-strip inside
`linked_abilities` this session. **I fixed the symptom there and left the cause
standing; this audit is what caught that.**

**PROPOSED FIX (DET, no vocabulary):** widen `ABILITY_WORD` to the printed
shape, then diff — it runs before every branch, so it is the highest-blast-radius
change on this list and must be measured, not assumed. **Do it first and alone.**

### FINDING 5 — the `etb` branch tests `enters` singular only — 43 lines

```
Kotis, Sibsig Champion   Whenever one or more creatures you control ENTER, …
Builder's Talent         Whenever one or more noncreature, nonland permanents you control ENTER, …
Anje, Maid of Dishonor   Whenever Anje and/or one or more other Vampires you control ENTER, …
```

`\benters\b` misses the plural. **This is the exact mirror of STEP-2A's
`enters as` defect** — there a plural-only test lost the singular; here a
singular-only test loses the plural. **Third instance of "an inflection is not a
shape" in four sessions.**

**PROPOSED FIX (DET, no vocabulary):** `\benters?\b` in the etb trigger test,
then diff. 43 lines, and `etb` is the largest trigger family (5,713) so the diff
must be read.

## 5. WHAT THE AUDIT SAYS ABOUT THE SESSION

**The six passes hold.** 2,166 gap lines closed, 62 lines moved OFF a wrong
ratified token, **zero regressions**, every moved line read.

**All four new defects are RECALL failures, and that is the pattern.** Not one
would appear in a gap census as *wrong* — only as absent, indistinguishable from
a shape the corpus does not contain. Recall inversion is the only method that
finds them, and it should run every audit rather than every third one.

**Two of the four are traps this project already recorded and fixed
elsewhere** — `~` is not a word character (fixed at two sites, live at a third)
and an inflection is not a shape (third instance). **A trap fixed at its
discovery site and not swept is not fixed.** The proposed follow-up is a
`grep`-driven sweep of both traps across every branch, not another point fix.
